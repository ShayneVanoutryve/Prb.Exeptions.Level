# Oefening 12: De Array-aggregator

Een programma moet de som van alle getallen in een integer-array berekenen. De array wordt hardcoded in het programma. De uitdaging is om een methode te schrijven die de som berekent, maar die een `ArgumentNullException` gooit als de meegegeven array `null` is.

## Voorbeeld van de console
```
De som van de array is: 55
```
(Wanneer de methode wordt aangeroepen met een null-array)
```
Fout: De array mag niet null zijn.
```

## Stappenplan
1.  **Maak een methode `BerekenSom`.** Deze methode accepteert een `int[]` als parameter en retourneert een `int`.
2.  **Controleer op `null`.** Binnen de methode, controleer als eerste of de meegegeven array `null` is. Zo ja, `throw new ArgumentNullException("array", "De array mag niet null zijn.");`.
3.  **Bereken de som.** Als de array niet `null` is, loop door de array met een `foreach`-lus en tel alle getallen bij elkaar op.
4.  **Retourneer de som.** Geef de berekende som terug.
5.  **Roep de methode aan in `Main`.** Maak in de `Main`-methode een `int[]` aan met wat getallen. Gebruik een `try-catch`-blok om de `BerekenSom`-methode aan te roepen en de `ArgumentNullException` op te vangen.
6.  **Test met `null`.** Roep de methode ook een keer aan met `null` om te zien of de exception correct wordt afgehandeld.
7.  **Toon het resultaat.** Toon de som of de foutmelding.
