# Oefening 20: De Bestandsnaam-validator

Een systeem vereist dat bestandsnamen geen ongeldige tekens bevatten. Een eenvoudige versie hiervan is controleren of een bestandsnaam geen spaties bevat. De gebruiker voert een bestandsnaam in. Als de naam spaties bevat, wordt er een `ArgumentException` gegooid.

## Voorbeeld van de console
```
Voer een bestandsnaam in: mijn_bestand.txt
Bestandsnaam is geldig.
```
```
Voer een bestandsnaam in: mijn bestand.txt
Fout: Bestandsnaam mag geen spaties bevatten.
```

## Stappenplan
1.  **Vraag om een bestandsnaam.**
2.  **Lees de invoer.**
3.  **Valideer de naam.** Gebruik een `try-catch`-blok.
4.  **Controleer op spaties.** Gebruik de `Contains(" ")` methode op de `string`. Als deze `true` is, `throw new ArgumentException("Bestandsnaam mag geen spaties bevatten.");`.
5.  **Vang de fout op.** Vang de `ArgumentException` op en toon de `Message`.
6.  **Toon succesbericht.** Als er geen fout is, toon een bevestiging.
7.  **Gebruik een `finally`-blok.** Toon de boodschap "Validatie voltooid." na elke poging.
