# Oefening 17: De String-omdraaier

Een programma moet een ingevoerde tekst omdraaien. De gebruiker voert een tekst in. De applicatie toont de omgedraaide tekst. Als de gebruiker niets invoert, moet er een foutmelding komen.

## Voorbeeld van de console
```
Voer een tekst in: Hallo wereld
dlerew ollaH
```
```
Voer een tekst in: 
Fout: Invoer mag niet leeg zijn.
```

## Stappenplan
1.  **Vraag om een tekst.**
2.  **Lees de invoer.**
3.  **Valideer de invoer.** Gebruik een `try-catch`-blok. Controleer of de `string` leeg is (`string.IsNullOrEmpty()`). Zo ja, `throw new ArgumentException("Invoer mag niet leeg zijn.");`.
4.  **Draai de string om.** Maak een methode die een `string` als input neemt. Converteer de `string` naar een `char[]` array, gebruik `Array.Reverse()` en maak er dan weer een nieuwe `string` van.
5.  **Roep de methode aan.** Roep de omdraai-methode aan vanuit het `try`-blok.
6.  **Vang de fout op.** Vang de `ArgumentException` op.
7.  **Toon het resultaat.** Toon de omgedraaide `string` of de foutmelding.
