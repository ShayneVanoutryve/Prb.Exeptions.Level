# Oefening 19: De E-mail Validator

Een registratieformulier heeft een simpele e-mailvalidator nodig. De gebruiker voert een e-mailadres in. De applicatie controleert of het e-mailadres een "@" teken bevat. Dit is een zeer simpele validatie. Als het "@" teken ontbreekt, wordt er een `FormatException` gegooid.

## Voorbeeld van de console
```
Voer uw e-mailadres in: gebruiker@example.com
E-mailadres is geldig.
```
```
Voer uw e-mailadres in: gebruiker.example.com
Fout: Ongeldig e-mailadres formaat. Het '@' teken ontbreekt.
```

## Stappenplan
1.  **Vraag om het e-mailadres.**
2.  **Lees de invoer.**
3.  **Valideer het e-mailadres.** Gebruik een `try-catch`-blok.
4.  **Controleer op "@".** Gebruik de `Contains()` methode op de `string`. Als `!email.Contains("@")`, `throw new FormatException("Ongeldig e-mailadres formaat. Het '@' teken ontbreekt.");`.
5.  **Vang de fout op.** Vang de `FormatException` op en toon de `Message`.
6.  **Toon succesbericht.** Als er geen fout is, toon een bevestiging.
7.  **Gebruik een `finally`-blok.** Toon de boodschap "E-mail validatie uitgevoerd." na elke poging.
