# Oefening 11: De Datumchecker

Een applicatie moet controleren of een ingevoerde datum een geldige datum is. De gebruiker voert een datum in als "dd-mm-jjjj". De applicatie valideert de datum.

## Voorbeeld van de console
```
Voer een datum in (dd-mm-jjjj): 25-12-2023
De datum 25-12-2023 is geldig.
```
```
Voer een datum in (dd-mm-jjjj): 32-12-2023
Fout: '32-12-2023' is geen geldige datum.
```
```
Voer een datum in (dd-mm-jjjj): vandaag
Fout: 'vandaag' is geen geldige datum.
```

## Stappenplan
1.  **Vraag de gebruiker om een datum.** Vraag om een datum in het formaat "dd-mm-jjjj".
2.  **Lees de invoer.** Lees de `string`-invoer.
3.  **Valideer de datum.** Gebruik een `try-catch`-blok. Probeer de `string` te parsen naar een `DateTime` object met `DateTime.ParseExact()`. Specificeer het formaat "dd-MM-yyyy".
4.  **Vang de fout op.** Een `FormatException` wordt gegooid als de `string` niet overeenkomt met het opgegeven formaat of geen geldige datum is. Vang deze op.
5.  **Toon het resultaat.** Toon een bevestiging als de datum geldig is, of een foutmelding als dat niet zo is.
