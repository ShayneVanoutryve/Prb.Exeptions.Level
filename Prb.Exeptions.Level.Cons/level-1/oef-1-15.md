# Oefening 15: De Toegangscode

Een beveiligd systeem vereist een toegangscode die exact 4 cijfers lang is. De gebruiker voert een code in. De applicatie valideert de code. Er moeten fouten worden afgehandeld voor codes die geen 4 cijfers lang zijn en voor codes die niet-numerieke tekens bevatten.

## Voorbeeld van de console
```
Voer de 4-cijferige toegangscode in: 1234
Toegang verleend.
```
```
Voer de 4-cijferige toegangscode in: 12345
Fout: De code moet exact 4 cijfers lang zijn.
```
```
Voer de 4-cijferige toegangscode in: 12ab
Fout: De code mag alleen cijfers bevatten.
```

## Stappenplan
1.  **Vraag om de toegangscode.**
2.  **Lees de invoer.**
3.  **Gebruik een `try-catch`-blok.** Start een `try`-blok om de validatie uit te voeren.
4.  **Controleer de lengte.** Controleer of de lengte van de `string` niet gelijk is aan 4. Zo ja, `throw new ArgumentException("De code moet exact 4 cijfers lang zijn.");`.
5.  **Controleer op cijfers.** Probeer de `string` te converteren naar een `int` met `int.Parse()`. Dit zal een `FormatException` gooien als er niet-numerieke tekens in zitten.
6.  **Vang de fouten op.** Vang de `ArgumentException` en `FormatException` afzonderlijk op en toon de juiste foutmelding.
7.  **Toon succesbericht.** Als er geen fouten zijn, toon "Toegang verleend.".
8.  **Gebruik een `finally`-blok.** Toon de boodschap "Validatiepoging beëindigd." na elke poging.
