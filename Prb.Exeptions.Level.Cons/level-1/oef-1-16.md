# Oefening 16: De BMI Calculator

Een gezondheidsapp berekent de Body Mass Index (BMI). De gebruiker voert gewicht (in kg) en lengte (in meter) in. De formule is `BMI = gewicht / (lengte * lengte)`. De applicatie moet ongeldige invoer (tekst, negatieve waarden, nul) voor zowel gewicht als lengte afhandelen.

## Voorbeeld van de console
```
Voer uw gewicht in (kg): 70
Voer uw lengte in (meter): 1.75
Uw BMI is: 22.86
```
```
Voer uw gewicht in (kg): -5
Fout: Gewicht kan niet negatief zijn.
```
```
Voer uw lengte in (meter): 0
Fout: Lengte kan niet nul zijn.
```

## Stappenplan
1.  **Vraag om gewicht en lengte.**
2.  **Lees de invoer.**
3.  **Valideer gewicht.** Gebruik een `try-catch`-blok. Converteer naar `double`. Vang `FormatException`. Gooi `ArgumentOutOfRangeException` voor negatieve waarden.
4.  **Valideer lengte.** Gebruik een apart `try-catch`-blok. Converteer naar `double`. Vang `FormatException`. Gooi `ArgumentOutOfRangeException` voor negatieve waarden of nul. Een lengte van 0 zou ook een `DivideByZeroException` veroorzaken, dus dit is een proactieve controle.
5.  **Bereken de BMI.** Pas de formule toe. Omsluit deze berekening in een `try-catch`-blok om een eventuele `DivideByZeroException` op te vangen, voor het geval de controle op nul in de vorige stap faalt.
6.  **Toon het resultaat.** Toon de berekende BMI of de juiste foutmelding.
